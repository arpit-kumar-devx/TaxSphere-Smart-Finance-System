📌 Overview

TaxSphere is a modern Freelance Management System developed using the MEAN Stack (MongoDB, Express.js, Angular, Node.js).

The platform is designed to help freelancers and self-employed professionals efficiently manage:

Clients
Projects
Invoices
Payments
Financial Records
Budgeting
Tax Estimation

TaxSphere provides an integrated dashboard with real-time analytics, secure authentication, financial reporting, and workflow management.

⚙️ Prerequisites

Make sure the following are installed:

Node.js (>= 18.0.0)
npm (>= 8.0.0)
MongoDB (>= 4.4)
Angular CLI (>= 17.0.0)
🔧 Installation
1️⃣ Clone Repository
git clone https://github.com/arpit-kumar-devx/TaxSphere-Smart-Finance-System.git
2️⃣ Navigate to Project
cd TaxSphere-Smart-Finance-System
3️⃣ Install Dependencies
npm run install:all
4️⃣ Configure Environment Variables

Create a .env file:

PORT=3000
MONGODB_URI=mongodb://localhost:27017/taxsphere
JWT_SECRET=your_secret_key
